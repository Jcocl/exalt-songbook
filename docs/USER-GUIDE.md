# EXALT Songbook: quick guide

## Open and navigate

Open the private Songbook link and sign in with ChatGPT if prompted. The site owner must approve access first.

Use **Songs**, **Lineups**, and **Saved** at the top on a computer or the bottom on a phone. The settings button opens your account, reading preference, and team controls. An internet connection is needed to open and save library records.

## Find and read a song

Search **Songs** by title, artist, part of a word, or remembered lyrics. For example, **From north to south** finds **Christ Be Magnified**. **Ctrl K** jumps to search on a computer.

Tap a song to open it. Switch between **Lyrics** and **Chords**, choose a performance **Key**, and use **A− / A+** to change text size. Changing the viewing key does not replace the saved arrangement. Tap the heart to keep the song in **Saved**.

The three-dot **More** menu contains **Edit song**, **Print / PDF**, **Download**, **Original file**, and **Song details**, where available. Notes and source information stay in Song details rather than filling the reader.

## Add or edit

Leaders and admins can choose **Add song**. Enter the title and lyrics or chord sheet; add the artist and key when available. **Preview** checks formatting. Optional BPM, language, tags, attribution, and notes are inside the collapsed **Song details** section.

Inline chords go immediately before their lyric position:

```text
{section:Verse 1}
[G]Example words at the [D/F#]right position
{comment:Repeat chorus twice}
```

For a pasted sheet with chords above lyrics, choose **Format pasted chords** and check the preview. Original pasted text is retained.

If a duplicate is detected, open the saved song or choose **Save arrangement** for another version. Use **Save as a separate song** only for a genuinely different song. A lineup reuses the saved song record.

## Import

1. In **Songs**, choose **Import**.
2. Choose **File** for PDF, Word, TXT, or ChordPro files up to 15 MB. Choose **Paste** for copied text, then **Review**.
3. Check each title and artist. Open **Lyrics & chords** to correct content and chord positions. **Import notes** contains extraction warnings.
4. Select the new songs and choose **Save selected**. Duplicate candidates offer **Use existing**, **Save arrangement**, or **Save separately**.

Scanned PDFs need transcription; automatic OCR is not included. Compare complex layouts with the original document. The supplied November 7, 2026 reference songs are already loaded and marked for review. After checking an import, open **Edit song → Song details** and mark **Sheet reviewed**.

## Prepare a lineup

Open **Lineups → New lineup**, or use **Create lineup** beside the Songs list. Set the name and date, add library songs, and use the arrows to reorder them. Each song can have a performance key, arrangement, and note. Keep the status **Draft** while preparing; select **Ready** when finished.

Open a saved lineup and tap its songs. **Previous / Next** move through the service. **Reuse lineup** starts another service with the same songs. Saved changes remain after a refresh.

## Print or download

On a song, choose the view and key, then **More → Print / PDF**. Select Save as PDF in the browser's print window if needed. **More → Download** saves TXT for lyrics or a ChordPro `.cho` file for chords.

A lineup's **Print** action prints its selected arrangements in service order. Check the print preview before sharing.

## Team and backup

In **Settings**, admins can assign roles after an approved visitor signs in once. **Member** reads songs and keeps personal saved songs; **Leader** also edits songs and lineups; **Admin** also manages roles and backups. Changing an app role does not itself grant site access.

If a saved song or lineup changes while you are editing, reopen the current record and review it before trying to save again. Stale edits are rejected rather than silently replacing someone else's work.

Admins can choose **Backup → Download backup**. It contains songs, arrangements, lineups, and file metadata, but not original file bytes, accounts, or personal favorites. Keep original documents separately.

**Restore backup** adds missing records and leaves existing records unchanged. The file chooser accepts JSON up to 1.5 MB and the restore supports up to 100 new songs and lineups combined. It does not undo changes to existing records.

Keep source attribution and use songs within the ministry's storage, printing, and sharing permissions.
